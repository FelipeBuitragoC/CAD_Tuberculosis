# CAD Tuberculosis

Proyecto orientado al desarrollo de un sistema CAD para el análisis de
radiografías de tórax relacionadas con tuberculosis.

El proyecto contempla el uso de análisis exploratorio de datos, Machine
Learning y Deep Learning para realizar tareas de:

- Detección de tuberculosis.
- Clasificación de radiografías.
- Segmentación de regiones de interés.
- Desarrollo de una aplicación para utilizar los modelos obtenidos.

## Estructura del repositorio

- `data/raw/`: datos originales sin modificar.
- `data/processed/`: datos procesados para análisis o entrenamiento.
- `notebooks/`: análisis exploratorios, preprocesamientos y pruebas.
- `models/`: modelos entrenados.
- `reports/figures/`: gráficas y resultados.
- `app/`: futuro desarrollo del software CAD.
